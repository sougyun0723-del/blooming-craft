# 그림이 피어나다
Stitch의 Blooming Craft Studio 설계를 바탕으로 만든 브라우저용 전사수업 웹앱입니다. 따뜻한 색상과 둥근 카드, 큰 버튼을 적용했습니다. 원본 설계는 source/stitch/에 보관했습니다.

## 실행
1. ZIP을 모두 압축 해제합니다.
2. index.html을 Chrome 또는 Edge에서 엽니다. 이 버전은 HTML 하나에 동작 코드를 내장해 index.html만으로도 실행됩니다. 인터넷 연결과 설치가 필요 없습니다.
3. 안정적인 저장을 위해 수업에서는 Netlify HTTPS 주소 또는 아래 로컬 서버 사용을 권장합니다. file:// 실행 시 저장 정책이 브라우저에 따라 다를 수 있습니다.

Python이 있으면 압축을 푼 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 에 접속합니다.

## 포함 기능
- 홈, 활동 선택, 그림 그리기, 굿즈 만들기, 교사 기록 이동
- 3개 활동 완료 토글, 완료 개수와 반올림한 백분율
- 터치/마우스 드로잉, 색상·굵기 선택, 크게 보기(Escape로 닫기), 다시 그리기
- 활동별 그림 자동 저장(선 그리기 종료 시), 명시적 그림 저장 및 PNG 다운로드
- 굿즈 선택, 그림 확인, 전사 과정·안전 안내, 굿즈 완료 기록
- 실제 완료/취소/그림 저장/그림 초기화/굿즈 선택/굿즈 완료 이벤트만 교사 기록에 표시
- CSV UTF-8 BOM과 따옴표 이스케이프 적용, 빈 기록일 때 다운로드 비활성화
- 앱 데이터만 전체 초기화. 같은 사이트의 다른 저장 키는 지우지 않음

## 저장 범위
키: `blooming-craft-v1`. localStorage에 그림 선 좌표, 색, 굵기, 선택 활동·굿즈, 완료 상태, 실제 이벤트 시각과 내용을 저장합니다. 개인 식별 정보 입력란, 로그인, 학교 DB, 알림 전송, IEP 자동 생성, 서버 통신, 외부 폰트·분석 도구는 없습니다. 교사 기록은 접근 제한 화면이 아니라 같은 브라우저의 조회 메뉴입니다.

같은 브라우저 프로필·같은 웹 주소에서 복원됩니다. 다른 기기/프로필, 다른 도메인, file://에서 HTTPS로 이동한 경우 자동 이전되지 않습니다. 시크릿 모드나 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. 저장 공간 부족 시 오류 메시지를 표시합니다. 그림이 많아지면 PNG와 CSV로 내려받아 보관하세요. CSV는 이벤트 목록이며 그림 백업이나 재가져오기 기능은 아닙니다.

## Netlify 배포 설정
사용자가 요청한 범위에 맞춰 배포 가능한 파일과 설정을 제공합니다. 실제 Netlify 계정에 업로드하거나 기존 사이트를 변경하지 않았습니다.
- 수동 배포: 압축 해제한 폴더(index.html이 바로 들어 있는 폴더)를 Netlify 수동 배포 영역에 올립니다.
- Git 연결: 이 폴더를 저장소 루트로 사용합니다. Build command는 비워두고 Publish directory는 `.`으로 지정합니다. netlify.toml도 동일하게 설정되어 있습니다.
- 빌드/Node 패키지 설치/환경변수가 필요 없습니다. 원본 source/stitch는 실행에 사용하지 않으며 공개하지 않으려면 배포 폴더에서 제외해도 됩니다.
- 접속 URL을 고정해야 같은 브라우저의 저장 기록을 계속 볼 수 있습니다.

## 파일
- index.html: 화면·반응형 스타일
- app.js: 메뉴와 드로잉·다운로드 동작
- core.js: 데이터 검증·저장·완료 계산 원본·CSV
- netlify.toml: 정적 배포 설정
- test.cjs: Node 기반 기능 연결 테스트(외부 패키지 불필요)
- TESTING.md: 자동 검사 결과와 실제 브라우저 확인 절차
- source/stitch/: 수정하지 않은 Stitch 원본

전사 기계 제어, 실물 굿즈에 대한 정확한 합성, 실물 크기 인쇄 및 좌우 반전은 구현 범위에 포함하지 않았습니다. PNG는 그림 원본입니다. 재료/장비에 맞는 인쇄와 온도·시간은 교사가 출력 프로그램 및 장비 설명서에서 확인합니다.

## 코드 수정 시 주의
실행본 index.html은 코드를 내장합니다. app.js/core.js를 변경했다면 실행본의 해당 script 블록도 갱신해야 합니다. 이번 배포본에서는 두 코드가 일치함을 검사했습니다.

## 공개 앱에서 설명하는 실제 범위
홈과 교사 기록 화면에 같은 범위 안내를 추가했습니다. 다른 기기에서 앱을 여는 것과 기록 공유는 다릅니다. 로그인·교사 호출·학교 DB·앱 자체의 데이터 암호화·IEP 생성은 미구현입니다. 전사 화면은 수업 안내이며 기계 제어 기능이 아닙니다.
현재 실행 HTML에는 외부 스타일·글꼴·이미지 의존성이 없습니다. 원본 Stitch 자료의 의존성과 구분합니다. 웹 서버에서 앱을 받아오는 접속은 인터넷이 필요하며, 오프라인 웹 캐시 기능을 보장하지 않습니다.

## 발표 때 사용할 설명
“현재 구현한 기능은 그림 그리기, 3개 활동의 완료·진행률 표시, 같은 브라우저에서의 저장·복원, 교사 기록 조회와 CSV 다운로드입니다. 기록은 이 기기·이 브라우저·이 사이트 주소에 저장되며 기기 간 자동 공유되지 않습니다. 전사 과정은 수업 안내이며 실제 기계를 제어하지 않습니다. 학교 DB, 실시간 교사 호출, 로그인, 앱 자체의 데이터 암호화, IEP 자동 생성은 구현하지 않았습니다.”
