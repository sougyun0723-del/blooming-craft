실제 기능과 미구현 기능 자세히 보기

실제 구현
5개 화면 이동, 3개 활동 완료 표시·진행률, 그림 그리기·저장·복원·초기화, 교사 기록 조회, PNG·CSV 다운로드.

미구현
학교 DB 연결, 교사 실시간 호출, 로그인, 앱 자체의 저장 데이터 암호화, IEP 자동 생성, 기기 간 자동 동기화.

안내 화면
굿즈 선택과 전사 순서는 수업 안내예요. 전사 기계 제어·자동 인쇄·실시간 전사 상태 확인은 하지 않아요. 자동 그림 평가나 IEP 생성 결과를 시연하지 않아요.

인터넷 사용
현재 실행본은 외부 스타일·글꼴·이미지를 불러오지 않아요. 다운로드한 HTML은 인터넷 없이 열 수 있어요. 웹 주소로 처음 접속하거나 새로 불러올 때는 인터넷 연결이 필요해요. 동봉된 Stitch 원본 설계는 실행본과 별개이며 외부 리소스 참조가 있을 수 있어요.

기록 관리
공용 기기에서는 다른 사용자가 같은 브라우저의 기록을 볼 수 있어요. 브라우저 데이터 삭제·시크릿 모드 종료·주소 변경 시 이전 기록을 사용할 수 없을 수 있어요. 필요한 그림과 CSV를 내려받아 보관하세요. 교사 기록 메뉴는 로그인으로 보호되는 화면이 아니에요.
